# Human Anchor と AI Orbit

## Human Anchor

本人の手動活動を上書きしません。Anchor が出たら AI 予定投稿を再評価します。

例: 手動 X / Instagram、新曲公開、ライブ告知・実施、MV、制作報告、本人コメント、My-SNS Seed、本人確認済み Taste、新素材。

SNS-AI の local history は使えますが、Bridge ingest が未接続のとき **「My-SNS の手動投稿を読んだ」とは言いません**。

## AI Orbit

Anchor の周囲に補助投稿を置きます。同じ文の言い直しは禁止です。

Human: 「今日はRe:tripを歌いました」

禁止: 「今日はRe:tripを歌いました」「Re:tripを聴いてください」

候補: 別時期の弾き語り、歌詞の別部分、旅に関する Taste、制作背景、別アレンジ、関連する別曲、ギターの切り口。

## Campaign Orbit

Release / Live / MV は Human Anchor Event です。Day+1 / +3 / +5… は初期の目安であり、反応・素材・手動投稿で変えます。本人告知を毎日コピーしません。

## No-post

「1日2投稿」は **maximum** であり minimum ではありません。本人が十分投稿している、テーマ過多、安全な素材がない、budget、Audience fatigue、Campaign 過多なら skip できます。
